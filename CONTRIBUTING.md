# Contributing

- Keep UI and API changes aligned.
- Document endpoint and response changes in `docs/API.md`.
- Add tests for CRUD behavior, invalid IDs, missing records, and database failures.
- Never commit database files, credentials, or personal task data.
- Run the API syntax check and available client tests before submitting.
- Do not introduce authentication shortcuts or expose database credentials in the browser.

The current package scripts are incomplete. If adding scripts, document the exact commands and keep the lockfile synchronized.
